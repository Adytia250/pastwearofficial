## 📌 About The Project

**Pastwear Official** is a modern e-commerce web platform dedicated to vintage, retro, and grunge aesthetic apparel. Built with a passion for timeless storytelling and classic fashion, the website provides an immersive shopping experience featuring curated clothing lines, brand philosophy narratives, customer reviews integrated with Google Sheets, and seamless redirection to official marketplace channels (Shopee & WhatsApp).

---

## 🛠️ Technology Stack

| Technology | Purpose / Description |
| :--- | :--- |
| **HTML5** | Semantic structure and layout design |
| **CSS3** | Custom styling, vintage aesthetic palette, and responsive design |
| **JavaScript (ES6+)** | Dynamic interactivity, DOM manipulation, and API integration |
| **Google Sheets API** | Lightweight backend database for customer reviews and testimonials |
| **GitHub Pages / Hosting** | Web deployment and hosting via `pastwearofficial.my.id` |

---

## ✨ Key Features

- **🏛️ Hero & Landing Section:** Aesthetic introduction featuring brand taglines, quick CTA buttons for exploring the shop, and smooth navigation.
- **📖 Brand Story ("Story"):** Deep-dive narrative into the inspiration behind Pastwear ("Nostalgia dalam Tiap Jahitan").
- **🛍️ Curated Collection Catalog:** Showcasing premium apparel lines (graphic tees, vintage prints) with clear pricing and article codes.
- **💬 Customer Reviews & Testimonials:** Interactive review section backed by Google Sheets integration where customers can share memories and read feedback.
- **📱 WhatsApp Direct Integration:** Quick-access floating or button-based WA chat for instant customer service and inquiries.
- **🛒 Explore Shop (Shopee Redirect):** Direct bridge connecting catalog items straight to the official Shopee marketplace store.

## 🎯 Challenges Solved

- **Lightweight Database Integration:** Successfully implemented Google Sheets as a dynamic backend database to fetch and display customer testimonials without heavy database overhead.
- **Vintage Aesthetic & Typography:** Crafted a cohesive retro-modern visual identity using custom color palettes, elegant serif typography, and balanced spacing.
- **Responsive Multi-Device Layout:** Designed fluid layouts ensuring seamless browsing across desktop monitors, tablets, and smartphones.
- **Seamless Marketplace Redirection:** Streamlined the user journey from brand discovery directly to external marketplace channels (Shopee & WhatsApp).
